# 🏢 ONTRM – Business Registration & Management Platform

Designed and developed a full-stack business registration platform from scratch, transforming the client's product vision and requirements into a complete responsive web application.

## 📌 Overview

ONTRM is a full-stack business registration and management platform designed to guide Ontario entrepreneurs through business registration, payment, document preparation, administrative review, and post-submission management.

Working from the client's business concept, requirements, and product direction, I designed and developed the application from the ground up — covering UI/UX, frontend and backend development, database architecture, authentication, payments, document automation, admin workflows, and production configuration.

🌐 **Live Website:** [ontrm.com](https://ontrm.com/)

## 🎯 Objectives

- Transform the client's product concept into a complete digital platform
- Simplify complex business registration into structured onboarding
- Support both sole proprietorship and incorporation workflows
- Build secure customer and administrator experiences
- Integrate authentication and online payments
- Automate registration document generation and delivery
- Create a responsive experience across desktop and mobile

- Designed the complete application experience from scratch
- Created the visual system, layouts, navigation, forms, dashboards, and reusable components

## ⚙️ Tech Stack

- **Framework:** Next.js 16
- **Frontend:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Database:** Supabase / PostgreSQL
- **Authentication:** Clerk
- **Payments:** PayPal, Stripe
- **Documents:** PDF-Lib, DOCX Templates, QR Codes, ConvertAPI
- **Architecture:** Next.js Server Actions & Route Handlers
- **Version Control:** Git / GitHub
